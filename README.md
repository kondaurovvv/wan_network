# Проектирование корпоративной сети между городами — Cisco IOS / PNETLab

## Навыки

| Область | Технологии |
|---|---|
| Адресация | IPv4/IPv6 dual-stack, планирование адресов, суммаризация |
| Коммутация L2 | VLAN, MSTP, EtherChannel (LACP/PAgP), HSRP |

## Проект — корпоративная сеть WAN

Проект объединяет четыре территориально распределённых офиса в единый  
маршрутизируемый домен.

```
   ┌───────────────────Киторн─┐
   │                     │    │          
   │    ┌──────────────Ламас  │            
   │    │                │    │          
   Москва────────────────Триада──────────────Санкт-Петербург
     │                                              │
     └──────────────────────────────────────────────┘
                     │            │
                 Чокурдах     Лабытнанги
```

| Работа | Тема | Что решено |
|---|---|---|
| [Адресация IPv4/IPv6](Stage1/IPv4-IPv6.md) | Планирование адресов | Разработан адресный план корпоративной WAN-сети, выполнено распределение IPv4/IPv6-подсетей и настроен Dual-Stack |


## Коммутация и маршрутизация

| Работа | Тема | Ключевой результат |
|---|---|---|
| VLAN | Сегментация L2 | Создание VLAN, настройка Access-портов и Trunk-соединений IEEE 802.1Q |
| MSTP | Предотвращение петель | Настройка MST-регионов и экземпляров MST, распределение VLAN, выбор Root Bridge и резервирование путей |
| EtherChannel | Агрегация каналов | Объединение физических интерфейсов в Port-channel с использованием LACP и настройкой 802.1Q Trunk |
| HSRP | Резервирование шлюза | Настройка Active/Standby, виртуальных шлюзов IPv4 и IPv6, приоритетов и Preemption |
| Inter-VLAN Routing | Маршрутизация между VLAN | Настройка Router-on-a-Stick, подынтерфейсов 802.1Q и маршрутизации IPv4/IPv6 между VLAN |

## Среда

- Симулятор: [PNETLab](https://www.pnetlab.com/)
- Платформа: Cisco IOS (маршрутизаторы, коммутаторы L3 и коммутаторы L2)
- Файлы топологий: в папке каждой работы
